# Provenance bukti

qa_report.historical.md adalah isi penuh field reports["qa_report.md"] dari JSON
pengguna untuk novel-7928de39d292, judul test 2, app_version 0.2.0. Angka dan isi
laporan dipertahankan; ini bukan laporan terbaru dari HP.

glossary.model-output-excerpt.md adalah CONTOH TABEL / kutipan pendek dari field
glossary pada JSON pengguna yang sama. Bukan glosarium penuh. Deklarasi RAW_KOREA
memang ada dalam output model itu walaupun config.sumber=EN_TRANSLATED dan doc_raw=null.
Pertahankan anomali ini saat audit; jangan menganggap Hangul dalam output sebagai
bukti adanya sumber Korea. Bang tercatat sebagai onomatope di glosarium; hal ini
belum membuktikan semua kemunculan Bang pada prosa merupakan onomatope.

Snapshot debug mentah lengkap pernah ditempelkan dalam percakapan, tetapi tidak
tersedia sebagai file asli pada workspace. Kita tidak menyusun ulang puluhan
record token/hash menjadi snapshot palsu. Lihat from_device/README.md untuk data
terbaru yang benar-benar perlu diambil di aplikasi.
