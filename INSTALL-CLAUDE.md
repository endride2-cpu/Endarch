# Sembilan skill untuk Claude Code

Ekstrak ZIP. Salin folder .claude ke root proyek yang dibuka di Claude Code.
Jika folder sudah ada, gabungkan skills tanpa menimpa settings milik pengguna.
Restart sesi Claude Code; ketik / atau sebut nama skill dalam prompt.

Daftar:
- impeccable
- ui-ux-pro-max
- systematic-debugging
- android-cli
- jetpack-compose-performance
- testing-setup
- anr-audit-and-fix
- ponytail
- caveman

Contoh: /ponytail full dan /caveman. Paket memasang skill inti keduanya,
bukan hook, proxy, status band, CLI tambahan, atau mode ultra/megacave.
Pakai Ponytail untuk perubahan minimum yang lengkap. Batasi Caveman ke komunikasi
agent/log coding; jangan memadatkan isi novel, prompt terjemahan, atau bukti QA.
Skill desain: sebut impeccable untuk desain utama, ui-ux-pro-max untuk referensi tambahan.

Installer dan skrip tidak dijalankan. Baca SKILL.md sebelum memakai fitur.
Tidak berisi source aplikasi, APK, kredensial, atau konfigurasi global.
Sumber dan commit upstream ada di .claude/skills-lock.json.
