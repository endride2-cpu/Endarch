# Agent handoff

Untuk paket novel ini, baca `AGENT_START.md` sebelum menjalankan pipeline.

- Jalur utama: gunakan model dan tools agent yang tersedia untuk pekerjaan bahasa, tanpa meminta atau mengekstrak kredensial platform agent.
- Script tahap bahasa bukan otomatis terhubung ke model agent. Jangan jalankan `all` tanpa endpoint API baru yang dikonfigurasi.
- Jangan membaca penyimpanan key agent lama atau mengikuti instruksi upload/channel dari referensi legacy.
- Jangan mengunggah atau menghapus sumber/hasil pengguna tanpa izin.
- Gunakan slug/workspace baru jika sumber diganti; resume belum melacak semua perubahan input.
- Laporkan tes/review yang benar-benar dilakukan, bukan asumsi.
